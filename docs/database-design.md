# SQLite 数据库

数据库位于 `DLE_DATA_DIR/incidents.sqlite3`。默认目录为用户主目录下的 `.autoloop/data`。数据目录需要具备本地写权限，数据库含原始错误日志，应按日志敏感程度保护访问。

| 表 | 内容和约束 |
| --- | --- |
| `incidents` | 故障编号主键、唯一指纹、时间、分类、严重级别、状态和非负计数 |
| `error_occurrences` | 关联故障的外键、唯一事件编号、文件位置、时间、原始日志和堆栈 |
| `scan_runs` | 扫描编号、项目、开始时间、状态以及统计和错误摘要的 JSON |
| `scan_issues` | 关联扫描记录的外键、文件位置和错误原因 |
| `file_offsets` | 每项目、每相对路径的文件身份和最后完整处理的偏移，供后续增量设计参考 |

扫描先提交 RUNNING 记录，再在写事务内处理故障、发生记录、文件位置和最终状态。单文件读取错误使用保存点回滚该文件，其他文件可继续提交。SQLite 操作失败时回滚扫描写事务，数据库仍可写时单独提交 FAILED。数据库整体不可写时，CLI 直接返回失败，进程被强制中断可能留下 RUNNING 记录。

SQLite 对写入串行化，扫描持有写事务。文件位置仅作为本次读取参考，全量扫描不会从该位置续读。
