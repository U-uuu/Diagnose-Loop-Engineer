# 故障事件管理

项目标识取规范化绝对路径的 SHA-256。事件指纹将项目标识、服务、异常类型、归一化消息及关键堆栈位置作为结构化数组进行 SHA-256。仅替换明确由用户、订单或请求标签引出的数字编号，保留状态码等普通数字。Python 堆栈选最后一个可识别的帧，Java 堆栈选第一个可识别的帧。保留行号以减少不同故障误合并，代码移动可能产生新指纹。

发生记录的唯一标识独立计算，使用项目、文件身份、行起始偏移和原始行内容哈希。同一文件改名后，在支持稳定文件身份的文件系统上仍可识别已有记录。轮转后新建的文件具有新身份，即使内容相同也能记录新发生。无法获取文件身份时使用项目相对路径。

聚合器按指纹新建或更新故障。重复发生记录不进入聚合。首次登记时间保留，最近发生时间取已收录记录中的最大时间，最新描述按该时间更新，原始证据可在发生记录中查询。严重级别保留已出现过的最高值。已解决的故障收到新发生记录后重新打开，重复扫描旧记录不会改变状态。

管理服务支持按编号和指纹查询、状态与严重级别及分类过滤、分页、发生记录、状态更新和总数统计。状态可在 OPEN、IN_PROGRESS、RESOLVED 之间切换。
