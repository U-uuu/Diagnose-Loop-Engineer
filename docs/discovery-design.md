# 故障发现

`cli/discovery.py` 调用 `application/services/discovery.py`。扫描器复用 M1 的目录枚举，并按 UTF-8 JSONL 流式读取，记录项目相对路径、从 1 开始的行号和从 0 开始的字节偏移。默认检查项目的 `logs/`，该目录缺失时检查项目根目录。默认仅扫描一层，`--recursive` 允许扫描子目录。

每行必须是 JSON 对象，包含带时区的 ISO 8601 字符串 `timestamp`，以及非空字符串 `level`、`service`、`message`。可选字符串为 `exception_type`、`exception_message`、`stacktrace`、`trace_id`，允许为 null。解析器将时间转换为 UTC，文件位置由扫描器覆盖。

检测器优先使用显式异常类型，其次检查堆栈和消息。ERROR、CRITICAL 和 FATAL 有故障证据，其他级别只有出现异常或具体的网络、超时、数据库错误关键词才被识别。分类器独立匹配异常类型和关键词，不匹配时归为 UNKNOWN。

单行超过 1 MiB 时计为解析错误，继续处理后续行。格式、编码和字段错误都记录位置。文件打开失败或扫描期间被替换、截断或写入时，回滚该文件的写入并继续其他文件。文件稳定后可重新运行。每次全量扫描只读取打开时已有的字节范围。完整扫描的问题记录可分页查询，单次摘要最多包含 100 条。

本阶段采用本地文件系统的文件身份和变更检查。扫描期间主动切换路径、重复使用文件身份或保留同一字节前缀的原地重写，无法在所有文件系统上可靠地区分。
